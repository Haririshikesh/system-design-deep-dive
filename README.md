# system-design-deep-dive
A Guide to high-scale system design. Featuring architectural blueprints, deep dives into trade-offs, and proof-of-concept implementations for real-world distributed systems.


## ROADMAP & PROGRESS

### 🛠️ 1. Foundational Utilities
- [ ] **Rate Limiter (Current Focus)** - Throttling API requests at scale.
- [ ] **URL Shortener** - TinyURL/Bitly clone with 100M+ DAU.
- [ ] **ID Generator** - Distributed unique IDs (Snowflake).
- [ ] **Notification System** - Multi-channel push/email/SMS.

## 🏗️ How this Repo is Structured
Each system design includes:
1. **Requirements Gathering:** Functional & Non-functional.
2. **Architecture Diagrams:** High-level and Low-level flows.
3. **Deep Dives:** Technical trade-offs (SQL vs NoSQL, Latency vs Consistency).
4. **PoC Implementation:** Minimal working code for the core logic.
